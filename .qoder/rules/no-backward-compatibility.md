# 开发态规则：不做向后兼容（收工前必须执行）

本项目当前处于持续开发态，使用者只有开发者本人。**任何改动都不需要考虑
历史场景与向后兼容**，直到用户明确宣布"收工"并要求移除本规则。

## 必须执行

1. 修改命令、接口、配置、目录结构时，直接替换为最新写法，**禁止**保留：
   - 旧参数 / 旧命令的兼容映射（参数别名、argv 预处理、子命令自动纠正等）；
   - 双写、迁移、兜底逻辑；
   - Deprecated 警告与"兼容期内"注释。
2. 删除即删除：被替换的文件、函数、参数直接移除，不留"转发壳"或占位存根。
3. 文档同步：README、模块 docstring、行内注释中的用法示例必须与代码同步
   更新为最新写法；文档与代码不一致视为缺陷。
4. 数据与存储：本地 / 进程内数据结构变更时直接改 schema，不做旧数据迁移。

## 例外

无。即使是 README 中已发布的命令示例，也按最新写法直接改。

## 移除条件

用户明确说"收工"（或同等表述）时，删除本规则文件，此后的改动恢复正常的
兼容性考量。
