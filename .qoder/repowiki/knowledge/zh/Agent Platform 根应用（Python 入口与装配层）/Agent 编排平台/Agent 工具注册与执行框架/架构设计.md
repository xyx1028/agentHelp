模块按职责拆分为四个文件：
- `registry.py` 定义核心数据模型 `ToolRegistration`（工具 + 可选超时）与不可变集合 `ToolRegistry`，集中暴露 `tools`、`timeouts_by_name`、`prompt_catalog()`、`bind_model()` 等只读视图，并通过 `replace()` 返回新实例供测试替换。
- `factory.py` 作为组合根 `build_default_tool_registry`，把领域客户端（`KnowledgeBase`、`OpenMeteoWeatherClient`）适配为 LangChain 工具后注入注册表，是新增工具的唯一入口。
- `executor.py` 的 `ReadOnlyToolExecutor` 基于 `ThreadPoolExecutor(max_workers=1)` 实现单工具级超时与异常兜底，将任何失败转为 `ToolMessage` observation，保证 LangGraph 图不崩溃。
- `rag.py` / `weather.py` 是具体工具的 LangChain 适配器，仅被 factory/executor 引用，不被外部直接依赖。
依赖方向单向：executor → registry；factory → registry + rag/weather；__init__.py 通过 `__all__` 白名单对外暴露契约。
