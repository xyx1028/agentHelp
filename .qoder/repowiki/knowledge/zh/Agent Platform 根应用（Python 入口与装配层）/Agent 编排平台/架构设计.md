agent_platform 是四个子模块的装配层：
- agent.py 中的 AssistantAgent 通过构造函数注入 model / ToolRegistry / AgentMemory，并在 ask() 中串行化一轮问答（加锁 → 读短期历史 + 召回长期记忆 → 驱动 LangGraph assistant⇄tools 循环 → 写回短期窗口并触发长期记忆 writer）。
- config.AgentSettings 作为不可变配置中心，统一持有 memory、tool_timeout_seconds、rag_top_k 等参数，并在 __post_init__ 中把旧字段 max_history_messages 与 MemorySettings 双向同步，所有子模块均从该 dataclass 读取运行时值。
- tools 子模块暴露 ToolRegistry/ReadOnlyToolExecutor/build_default_tool_registry，被 agent 绑定模型 schema 并注入系统 Prompt 的工具目录；evaluation 子模块通过 fakes 替换同一接口做离线断言。
- memory 子模块暴露 AgentMemory/MemoryScope 门面，agent 在构造时默认创建 in_memory 实例，共享 memory 时必须显式传入 scope 以防止跨用户串数据。
- evaluation 不直接依赖 agent 内部实现，而是复用 tools.fakes 与 memory 契约对同一边界进行回归测试。
四者通过 Python 包级 import 耦合，无外部服务或消息总线。
