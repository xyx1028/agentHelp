模块以 `agent.py` 中的 `AssistantAgent` 为应用层入口，通过构造函数注入模型、`ToolRegistry`、`AgentMemory` 和 `MemoryScope`，实现松耦合的可替换边界。

- 顶层包：`config.AgentSettings`（不可变 dataclass，集中超时、窗口、RAG 等参数并提供 Fail Fast 校验）、`rag.KnowledgeBase`、`weather.OpenMeteoWeatherClient` 作为外部依赖适配层。
- `memory/` 子包按单向依赖分层：`models`（数据模型）→ `contracts`（接口契约）→ `short_term` / `long_term` / `writer`（进程内实现）→ `service.AgentMemory`（组合门面），对外仅暴露 `__all__` 白名单。
- `tools/` 子包：`registry.ToolRegistry` + `executor.ReadOnlyToolExecutor` 构成工具执行边界，`factory.build_default_tool_registry` 是新增工具的唯一装配点，内置 weather 与 RAG 工具。
- `evaluation/` 子包：离线、无网络回归测试套件，用 `fakes.MockScenario` 与 `create_mock_model` 模拟模型/工具调用，由 `runner.EvaluationRunner` 驱动用例集断言路由、observation 与最终答复。
- 核心编排链路在 `AssistantAgent.ask`：加锁 → 加载短期历史 + 召回长期记忆 → 驱动 LangGraph `assistant ⇄ tools` 状态图循环 → 写回短期窗口并提取长期偏好 → 取最后一条非工具调用的 AI 消息作为答案。
- 所有对外 API 通过各包的 `__init__.py` 中 `__all__` 白名单收敛，内部布局重构不影响调用方。
