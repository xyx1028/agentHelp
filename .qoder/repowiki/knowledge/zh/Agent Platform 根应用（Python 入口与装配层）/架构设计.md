main.py 是跨子模块的唯一装配点：通过 python-dotenv 加载 MODEL_API_KEY / MODEL_NAME / MODEL_BASE_URL，由 agent_platform.config.AgentSettings 消费；根据 --mock / --evaluate 切换注入策略——--mock 使用 evaluation 子模块的 create_mock_model 与 create_mock_tool_registry，--evaluate 直接短路调用 run_evaluation 返回退出码，真实模式则经 langchain.chat_models.init_chat_model 创建 OpenAI 兼容模型并由 AssistantAgent 统一绑定 ToolRegistry；MemoryScope(tenant_id/user_id/conversation_id) 作为跨 Agent 实例的隔离边界。子模块之间不直接互相 import，而是经由 main.py 组装后以构造函数参数注入。web_api 提供 FastAPI 会话与聊天 REST 接口并托管 web_ui 的 SPA 静态资源，三者通过 HTTP API 解耦。
