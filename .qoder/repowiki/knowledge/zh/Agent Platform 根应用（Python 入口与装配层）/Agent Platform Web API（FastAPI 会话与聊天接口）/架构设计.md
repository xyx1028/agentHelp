模块以 `app.py` 的 `create_app` 为唯一装配点：接收外部注入的 `AssistantAgent` 与 `ConversationRegistry`，挂载 CORS、路由和可选的前端构建产物。
- `routes/chat.py` 通过 `build_chat_router` 工厂函数返回 `APIRouter(prefix="/api/conversations")`，按资源域组织；依赖经闭包注入而非全局单例，便于测试替换。
- `schemas.py` 用 Pydantic `BaseModel` 集中定义请求/响应 DTO，路由层只做参数校验与领域对象映射。
- `sessions.py` 提供进程内线程安全的 `ConversationRegistry`（`RLock` + dict），作为会话元数据的持久化抽象，未来可被数据库实现替换而不影响路由层。
- 依赖方向单向：routes → schemas/sessions → agent_platform.agent/memory；应用层不感知模型是真实还是 mock。
