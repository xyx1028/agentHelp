- 运行时参数集中放在不可变的 dataclass（AgentSettings、MemorySettings），并通过 __post_init__ 做 Fail Fast 校验与字段同步。
- 对外扩展点（模型、工具注册表、记忆门面）一律通过构造函数注入，便于 evaluation 用 fakes 替换。
- 多用户/多会话隔离通过 MemoryScope 显式传递，共享 memory 实例时强制要求指定 scope。
- 系统 Prompt 由 AgentSettings.build_system_prompt 根据当前 ToolRegistry.prompt_catalog() 动态拼接，新增工具无需维护提示词。
