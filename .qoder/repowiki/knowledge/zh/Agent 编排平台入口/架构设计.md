main.py 是唯一的进程入口，承担跨子模块的装配职责：
- 通过 python-dotenv 加载 .env（MODEL_API_KEY / MODEL_NAME / MODEL_BASE_URL），由 agent_platform.config.AgentSettings 消费；
- 根据 --mock / --evaluate 切换注入点：--mock 使用 evaluation 子模块提供的 create_mock_model 与 create_mock_tool_registry，--evaluate 直接短路调用 run_evaluation 返回退出码；
- 真实模式下通过 langchain.chat_models.init_chat_model 创建 OpenAI 兼容模型，再由 agent_platform.agent.AssistantAgent 统一从 ToolRegistry 绑定工具，保证 Prompt 中的工具声明与实际实现一致；
- MemoryScope(tenant_id/user_id/conversation_id) 作为跨 Agent 实例的隔离边界，默认仅进程内隔离。
子模块之间不直接互相 import，而是经由 main.py 组装后以构造函数参数注入。
