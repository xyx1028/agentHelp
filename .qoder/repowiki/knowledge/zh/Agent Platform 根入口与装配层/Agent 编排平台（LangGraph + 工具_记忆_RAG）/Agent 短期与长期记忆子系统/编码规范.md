- 所有跨作用域共享的可变状态（短期消息 dict、长期记录 dict、scope 锁表）均用 threading.RLock 保护，读写路径以 with self._lock: 包裹临界区。
- 数据模型统一使用 @dataclass(frozen=True)，并在 __post_init__ 中做 fail-fast 校验（非空、数值下限、时区存在性），构造后禁止外部篡改。
- 对外暴露的 API 通过包级 __init__.py 的 __all__ 白名单集中导出，未列出的内部符号视为实现细节。
- 可替换的后端通过 typing.Protocol 定义契约（ShortTermMemory / LongTermMemory / LongTermMemoryWriter），具体实现无需显式继承即可被类型检查器认可。
- 长期记忆的 id 采用 sha256(scope.tenant_id + NUL + scope.user_id + NUL + kind.value + NUL + content) 前缀截断，保证同内容幂等覆盖而不累积重复记录。
