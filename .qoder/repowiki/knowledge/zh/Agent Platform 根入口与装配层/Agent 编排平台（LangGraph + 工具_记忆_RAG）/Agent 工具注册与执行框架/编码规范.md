- 新增工具通过 `create_xxx_tool(...)` 适配器函数包装领域客户端并返回 `ToolRegistration`，再在 `build_default_tool_registry` 中集中注册。
- 对外的工具集合以 `ToolRegistry` 不可变对象承载，构造时校验名称唯一性，修改走 `replace()` 返回新实例而非原地变更。
- 工具超时采用两级裁决：`ToolRegistration.timeout_seconds` 优先，否则回落到 `ReadOnlyToolExecutor.default_timeout_seconds`。
- 工具执行失败（未注册、超时、异常）统一转换为文本 `observation` 写入 `ToolMessage`，不在调用链上抛出。
