- 评测数据对象统一使用 `@dataclass(frozen=True)` 定义，保证案例与结果不可变且可哈希。
- 案例通过 `scenario` 字符串（取值对应 `MockScenario` Literal）+ `city` 参数化复用 fakes，而非在 cases 中硬编码工具行为。
- 断言采用「收集失败描述列表」模式：`_collect_failures` 返回全部失败原因，`EvaluationResult.passed` 由 failures 是否为空派生。
- 执行器通过 `Protocol`（`EvaluationCaseExecutor`）暴露 `execute(case) -> EvaluationExecution` 契约，Runner 默认注入 `OfflineToolCaseExecutor` 但允许外部替换。
- 报告器与执行器均支持注入：`EvaluationRunner.__init__` 接受可选 executor，`ConsoleReporter.write` 接受可选 stream，便于 CI 或仪表盘集成。
