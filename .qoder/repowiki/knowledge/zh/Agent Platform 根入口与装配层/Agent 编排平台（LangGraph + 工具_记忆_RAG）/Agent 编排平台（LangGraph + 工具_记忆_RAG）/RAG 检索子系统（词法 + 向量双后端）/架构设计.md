模块以 `models.py` 中的 `KnowledgeBase`（`typing.Protocol`）作为唯一抽象边界，定义 `chunk_count` 属性与 `search(query, top_k)` 方法；`lexical.LexicalKnowledgeBase` 实现纯 Python 的词项倒排索引（按 `## [source-id] 标题` 章节解析 Markdown，中文双字词/英文整词分词），用于评测、mock 与无 embedding 环境兜底；`vector.LlamaIndexKnowledgeBase` 实现基于 Chroma 本地持久化集合的语义检索，支持 fastembed 与 OpenAI 兼容 API 两种 embedding provider，并复用 lexical 的 `parse_sections` 保证 `[source:...]` 引用契约一致。`factory.build_knowledge_base` 是装配入口，依据 `AgentSettings.rag_backend` 在构造时选择后端，embedding 机密通过参数显式注入而非读取环境变量。依赖方向单向：lexical/vector → models；factory → lexical/vector/models；上层工具仅依赖 `KnowledgeBase` Protocol。
