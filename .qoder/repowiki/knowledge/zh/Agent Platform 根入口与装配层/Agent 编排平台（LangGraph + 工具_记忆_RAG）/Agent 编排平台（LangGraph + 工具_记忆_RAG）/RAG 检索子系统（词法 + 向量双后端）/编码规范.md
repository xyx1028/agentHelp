- 后端实现通过 `typing.Protocol`（`KnowledgeBase`）暴露统一契约，新增后端只需实现 `chunk_count` 与 `search` 并在 factory 注册。
- 构造器采用 Fail Fast 策略：对非法参数、缺失语料、未安装依赖直接抛出 `ValueError`/`RuntimeError`，由调用方感知配置问题。
- embedding 机密（API Key、base_url）通过构造函数参数显式注入，不读取环境变量，保持 `AgentSettings` 不含敏感信息。
- Markdown 语料统一遵循 `## [source-id] 标题` 章节格式，由 lexical 的 `parse_sections` 解析并被 vector 复用，确保两个后端的来源引用一致。
- 重型第三方依赖（llama_index、chromadb、Document、SimpleDirectoryReader）采用函数内惰性 import，避免评测走 lexical 后端时被连带加载。
