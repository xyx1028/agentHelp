模块由三个职责正交的文件组成：
- agent.py：定义 `AssistantAgent` 应用类与 `AgentState`/`AgentTurn` 数据模型，通过构造函数注入 model、tool_registry、memory 等依赖，内部用 LangGraph `StateGraph` 构建 assistant→tools 条件循环图；`ask()` 在 `memory.turn(scope)` 上下文管理器内串行执行一轮问答，负责短期历史加载、长期记忆召回、图执行与结果写回。
- config.py：以不可变 `@dataclass(frozen=True)` 暴露 `AgentSettings`，在 `__post_init__` 中做 Fail Fast 校验并双向同步旧字段 `max_history_messages` 与新 `MemorySettings.short_term_max_messages`；`build_system_prompt()` 将注册表提供的工具目录拼接为最终系统提示词。
- weather.py：无状态 `OpenMeteoWeatherClient`，两步调用 Open-Meteo（地理编码→经纬度→预报），所有网络/解析异常统一收敛为自定义 `WeatherServiceError`，上层工具适配层只需捕获该单一异常。
依赖方向单向向外：agent.py → config.py + memory/tools；weather.py 独立于 Agent 体系，仅被 tools 层作为外部服务客户端使用。
