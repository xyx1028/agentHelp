agent.py 中的 AssistantAgent 是唯一的装配点：构造时从 config.AgentSettings 读取全局参数，调用 tools.build_default_tool_registry 生成 ToolRegistry 并绑定模型 Schema，再用 memory.AgentMemory 提供带作用域的会话窗口与长期偏好；ask() 通过 LangGraph StateGraph 在 assistant 与 tools 两个节点间循环，memory_context 作为不可信 HumanMessage 注入而非 SystemMessage，最终由 ReadOnlyToolExecutor 执行工具调用。
- 子模块边界：tools 负责工具发现与执行，memory 封装短/长期记忆接口，rag 提供向量与词法双后端检索，evaluation 用 fakes 替换模型与工具做离线回归，core_orchestration 暴露天气等具体工具与配置。
- 跨子模块契约：AgentSettings 是单一事实源，所有可调参数（tool_timeout_seconds、rag_top_k、rag_backend 等）集中在此并通过 __post_init__ 校验；memory_scope 是隔离用户数据的关键边界，共享 AgentMemory 必须显式传入 scope。
- evaluation 通过注入 fake model、fake tool registry 和 in-memory memory 复用同一 AssistantAgent 路径，保证线上与离线行为一致。
