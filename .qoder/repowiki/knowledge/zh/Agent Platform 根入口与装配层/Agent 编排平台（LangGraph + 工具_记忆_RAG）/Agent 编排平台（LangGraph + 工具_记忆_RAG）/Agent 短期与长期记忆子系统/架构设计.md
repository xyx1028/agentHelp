模块按单向依赖分层组织：`models.py` 定义不可变数据模型（`MemoryScope`/`MemoryOwner`/`MemoryRecord`/`MemoryQuery`/`RetrievedMemory`/`MemorySettings`），`contracts.py` 通过三个 `Protocol`（`ShortTermMemory`、`LongTermMemory`、`LongTermMemoryWriter`）声明稳定接口边界；`short_term.py`、`long_term.py`、`writer.py` 分别给出进程内默认实现；`service.py` 中的 `AgentMemory` 作为组合门面，仅依赖 Protocol 而非具体类，并通过 `in_memory()` 工厂装配默认后端。

- 隔离边界：短期记忆以 `MemoryScope`（tenant+user+conversation 三级）为单位隔离；长期记忆以 `MemoryOwner`（tenant+user 两级）为单位跨会话召回。
- 并发安全：`AgentMemory.turn` 为每个 `MemoryScope` 分配一个 `RLock`，串行化同一会话的读—执行—写流程；`InMemoryShortTermMemory` 与 `InMemoryLongTermMemory` 各自用 `RLock` 保护内部 dict。
- 长期记忆检索：基于正则分词（英文整词 + 中文双字 bigram）的词面重叠打分，无命中时回退到用户最新记忆；写入侧 `ExplicitPreferenceWriter` 仅识别「请记住」开头的显式授权消息，并用 sha256 生成确定性 id 实现幂等覆盖。
- 对外暴露：`__init__.py` 通过 `__all__` 白名单导出公共 API，内部实现不直接暴露。
