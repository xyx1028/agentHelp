- 数据模型统一使用 `@dataclass(frozen=True)` 构造不可变对象，并在 `__post_init__` 中做 Fail Fast 校验（非空、范围、时区等）。
- 对外契约通过 `typing.Protocol` 声明（`ShortTermMemory` / `LongTermMemory` / `LongTermMemoryWriter`），实现类无需显式继承，由类型检查器按结构匹配。
- 共享可变状态（会话消息字典、记录字典、作用域锁表）均用 `threading.RLock` 保护，读写路径在临界区内只做最小操作。
- 长期记忆的 id 采用确定性生成（sha256 拼接 tenant/user/kind/content），使重复保存等价于幂等覆盖，避免累积。
- 面向用户的不可信文本在注入 Prompt 前经 JSON 编码并转义 `<`/`>`，包裹在 `<remembered_user_data>` 标签中以防提示注入。
