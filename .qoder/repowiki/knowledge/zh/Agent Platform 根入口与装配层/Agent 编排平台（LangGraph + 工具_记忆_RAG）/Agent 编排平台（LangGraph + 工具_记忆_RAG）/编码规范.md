- 运行期可调参数集中在 AgentSettings dataclass 中，新增能力通过字段扩展并在 __post_init__ 做 Fail Fast 校验。
- 外部依赖（model、ToolRegistry、AgentMemory）均通过构造函数注入，便于 evaluation 用 fake 实现替换。
- 用户数据（memory_context、长期偏好）以 HumanMessage 形式注入，不提升为 SystemMessage，避免指令注入风险。
- 多会话/多用户隔离通过 MemoryScope 显式传递，共享 AgentMemory 时必须指定 scope，否则构造时报错。
- RAG 后端通过 rag_backend 字符串选择 vector/lexical，embedding provider 通过 rag_embedding_provider 选择 fastembed/openai，均为枚举式开关。
