模块按职责分为四层：
- 模型层 `registry.py`：定义不可变的 `ToolRegistration`（工具 + 可选超时）与 `ToolRegistry`，集中暴露 tools 列表、超时映射、Prompt 目录与 bind_model 适配，避免模型 Schema / Prompt / 执行器三处手工维护不同步。
- 装配层 `factory.py`：作为组合根，通过 `build_default_tool_registry` 将领域客户端（`KnowledgeBase`、`OpenMeteoWeatherClient`）经各自适配函数包装成 LangChain 工具并注入注册表；knowledge_base / weather_client 以可选参数形式注入，便于测试替换。
- 执行层 `executor.py`：`ReadOnlyToolExecutor` 基于 `ThreadPoolExecutor(max_workers=1)` 对每个工具调用施加超时，并将未注册、超时、异常统一转为文本 observation，保证 LangGraph 图不崩溃。
- 具体工具适配 `rag.py`、`weather.py`：把领域对象封装为 `BaseTool`，仅被 factory 与 executor 间接依赖。
依赖方向单向：executor → registry ← factory → (rag, weather)；包对外契约由 `__init__.py` 的 `__all__` 严格限定为 `ReadOnlyToolExecutor`、`ToolRegistration`、`ToolRegistry`、`build_default_tool_registry`。
