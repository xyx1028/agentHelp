顶层 agent.py 通过 config.py 加载配置并组装各子模块：tools.factory 提供 ToolRegistry 与组合工厂，memory.service.AgentMemory 暴露统一的会话窗口与长期偏好接口，rag.factory 按策略返回 lexical/vector 检索器；evaluation 套件则复用同一套 registry/memory/rag 契约，用 fakes 替换外部依赖进行离线断言。子模块之间不直接耦合，而是通过 Python 包内显式导入的抽象（如 memory.contracts、tools.registry、rag.models）协作，使编排层可在真实运行与评测两种模式下切换。
