模块为独立的前端工程，入口 `src/main.tsx` 使用 `createBrowserRouter` 注册 `/` 根布局与 `/c/:conversationId` 直链两个路由，均渲染 `ChatView`；`App.tsx` 仅作为 `<Outlet />` 占位以便后续扩展全局导航/登录态。
- 视图层：`src/views/ChatView.tsx` 承载主聊天页面，`src/components/ConversationList.tsx` 作为可复用组件。
- API 层：`src/api.ts` 集中封装所有 HTTP 调用，暴露 typed `api` 对象（listConversations/createConversation/deleteConversation/listMessages/sendMessage），组件只消费该对象而不直接 fetch。
- 构建与部署：`vite.config.ts` 在开发模式通过 Vite dev server 将 `/api` 反向代理到 `http://localhost:8000`（FastAPI），生产模式下由 FastAPI 直接托管 `dist/` 产物；`package.json` 的 build 脚本先跑 `tsc` 再 `vite build`，类型检查与打包串联执行。
