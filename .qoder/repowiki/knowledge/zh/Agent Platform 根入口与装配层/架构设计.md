main.py 是仓库唯一进程入口，承担三项职责：
- 子命令分发：chat（CLI 问答）、evaluate（离线回归）、ingest/reindex（向量索引维护）、serve（启动 FastAPI）；其中 evaluate/ingest/reindex 为短路流程，不进入 Agent 主循环。
- 装配中心：build_agent() 根据 --mock 切换真实/替身模型与 ToolRegistry，并按 RAG_BACKEND 构建 KnowledgeBase，再将 model + tool_registry + AgentMemory(MemoryScope) 注入 AssistantAgent，供 chat 与 serve 复用同一实例。
- 跨模块桥接：serve 子命令延迟导入 web_api.app.create_app，将已装配的 agent、ConversationRegistry、KnowledgeBase 以及 web_ui/dist 静态目录一并传入，使 web_api 仅消费装配后的对象而不直接依赖 agent_platform 内部实现；web_ui 通过 Vite 代理 /api 到 FastAPI，形成前端→后端→Agent 的单向调用链。
- 配置边界：.env 由 python-dotenv 加载，MODEL_* 用于创建 LLM，RAG_* 覆盖 AgentSettings，EMBEDDING_* 仅在 build_knowledge_base 处读取以避免机密泄露到可打印配置对象。
