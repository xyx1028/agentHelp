模块以 `app.py` 的 `create_app` 为唯一装配点：外部入口构造 `AssistantAgent`、`ConversationRegistry`、可选的 `KnowledgeBase` 后注入，由该函数完成 CORS、路由注册与 SPA 静态文件挂载。
- 路由按资源域拆分在 `routes/` 下（`chat.py`、`knowledge.py`），每个子模块通过工厂函数（如 `build_chat_router`、`build_knowledge_router`）返回独立的 `APIRouter(prefix=...)`，再由 `app.include_router` 平级挂载；新增业务接口只需追加文件并在 `__init__.py` 中注册。
- `schemas.py` 集中 Pydantic DTO，`sessions.py` 提供进程内线程安全的 `ConversationRegistry`，二者被路由层共享但与应用装配解耦。
- 依赖方向单向：routes → schemas/sessions → agent_platform.agent/memory 与 agent_platform.rag.KnowledgeBase；应用层不感知模型是真实还是 mock，mock 装配时知识库端点回 409。
- 前端 SPA 通过自定义 `SPAStaticFiles` 对非 `/api` 路径做 404→index.html 回退，路由注册在前、静态挂载在后以保证 `/api/*` 优先匹配。
