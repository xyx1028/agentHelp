模块通过工厂函数 `build_knowledge_router(knowledge_base)` 接收外部注入的 `LlamaIndexKnowledgeBase` 实例并返回一个 `APIRouter(prefix="/api/knowledge")`，将路由装配与后端实现解耦。
- 依赖方向：仅向上依赖 `agent_platform.rag.LlamaIndexKnowledgeBase` 与同包下的 schemas（`IngestDocumentsOut`、`KnowledgeStatsOut`、`ReindexOut`），不反向引用上层应用。
- 能力门控：内部 `require_vector()` 辅助函数在运行时检查 `knowledge_base` 是否为向量后端；若为 mock/词法后端则统一返回 HTTP 409，前端依据 `/stats` 返回的 `manageable` 字段决定是否暴露管理入口。
- 三个端点职责清晰：`GET /stats` 返回可管理性与片段数；`POST /documents` 逐文件写入临时目录后调用 `ingest`，单个失败不影响其余，全部失败时整体 400；`POST /reindex` 清空并重建索引，因共享同一实例，重建后 Agent 检索立即生效。
